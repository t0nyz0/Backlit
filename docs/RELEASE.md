**Backlit 0.2.4**

- Fixed closed-lid output so the logo follows the selected behavior.
- Added Typing as its own behavior, with clearer Input Monitoring guidance.
- Improved Music’s intensity range. Audio capture now starts and stops with Music mode.
- Remembered the closed-lid setting across restarts and updates without resetting an active timer. Enable it once after updating from an older version.
- Fixed Trackpad and agent-state output, and improved clean quit and recovery.
- Cleaned up the app icon and reduced preview rendering work.

After updating, macOS may require you to re-add Backlit under Input Monitoring.
